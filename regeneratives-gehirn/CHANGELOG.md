# Changelog

### Erstveröffentlichung
- 9 vollständige Module mit je 3 Lektionen
- KI-Vorlesefunktion mit Web Speech API (weibliche Stimme)
- Quiz-System mit sofortigem Feedback
- Reflexionsfragen mit Eingabefeld
- Fortschritts-Tracking (Module, Lektionen, Quiz)
- Abschluss-Screen nach Modul 9
- Mobil-optimiertes Design
- Offline-fähig (eine einzige HTML-Datei)
- Medizinischer Disclaimer integriert
- Wissenschaftliche Quellen dokumentiert
