# 🧠 Das regenerative Gehirn

**Selbstlernkurs – Stressmanagement & Burnout-Prävention**

Ein vollständiger E-Learning-Kurs als eigenständige Web-App – kein Server, kein Backend, keine Installation erforderlich. Einfach öffnen und lernen.

---

## 📖 Über diesen Kurs

Mentale Erschöpfung ist kein Zeichen von Schwäche – sie ist ein biologisches Signal. Dieser Kurs vermittelt auf Basis aktueller Neurowissenschaften und Lebensstilmedizin, wie das Gehirn gezielt regeneriert werden kann.

Der Kurs basiert auf gesicherter wissenschaftlicher Forschung aus den Bereichen Neurobiologie, Schlafmedizin, Ernährungswissenschaft, Bewegungsforschung und Psychologie. Alle Inhalte sind mit unabhängigen Peer-reviewed-Studien belegt.

## ✨ Features

- ✅ **Vollständiger Kurstext** – wissenschaftlich fundierte Lerneinheiten pro Modul
- 📊 **Fortschritts-Tracking** – Lektionen, Module und Quiz werden live verfolgt
- 🧩 **Quiz mit sofortigem Feedback** – Antworten werden erklärt, nicht nur bewertet
- 💬 **Reflexionsfragen** – mit eigenem Eingabefeld nach jeder Lektion
- 📱 **Mobil-optimiert** – funktioniert auf Smartphone, Tablet und Desktop
- 🔒 **Offline-fähig** – eine einzige HTML-Datei, kein Internet nötig
- 🎨 **Ruhiges, lernfreundliches Design** – kein visuelles Rauschen
- 🏆 **Abschluss-Screen** – nach erfolgreichem Durchlauf aller Module

## 🚀 Starten

### Option 1 – Direkt im Browser

1. [`index.html`](index.html) herunterladen
2. Im Browser öffnen – fertig

Keine Installation. Keine Registrierung. Keine Internetverbindung nötig.

### Option 2 – GitHub Pages (kostenlos, online erreichbar)

1. Repository forken oder klonen
2. Gehe zu **Settings → Pages**
3. Wähle **Branch: main** → **/ (root)** → **Save**
4. Nach 1–2 Minuten erreichbar unter:

```
https://DEIN-USERNAME.github.io/regeneratives-gehirn
```

### Option 3 – Lokal klonen

```bash
git clone https://github.com/DEIN-USERNAME/regeneratives-gehirn.git
cd regeneratives-gehirn
open index.html
```
